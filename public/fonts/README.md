# Switzer Webfonts

Self-hosted Switzer variable fonts from Fontshare (Indian Type Foundry).

## Files

- `Switzer-Variable.woff2` — variable font, weights 100–900
- `Switzer-VariableItalic.woff2` — variable italic, weights 100–900

The variable files cover every weight, so no static files are shipped.

## Configuration

Loaded in `src/styles/base/fonts.css`; family tokens live in `src/styles/theme/colors.css`.
